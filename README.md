# 그랑프리 스트라이더

한국어 반응형 세계관 사이트입니다. 별도의 설치나 빌드가 필요 없습니다.

## GitHub Pages에 올리기

1. 이 폴더 안의 파일을 GitHub 저장소 최상위에 업로드합니다. index.html이 최상위에 있어야 합니다.
2. 저장소 Settings → Pages에서 Source를 Deploy from a branch로 선택합니다.
3. Branch는 main, 폴더는 /(root)로 선택하고 Save를 누릅니다.
4. 배포가 끝나면 Pages에 표시된 주소로 접속합니다.

[GitHub 공식 안내](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)

## 이미지 추가와 교체

images.js에서 해당 선수 번호의 portrait(프사), casual(평상복), race(경기복)를 수정합니다. 이미지 URL 또는 상대 경로를 사용할 수 있습니다. 평상복은 현재 null이며 준비 중으로 표시됩니다. 프사는 832×1216 비율, 전신은 잘리지 않도록 표시됩니다.

현재 프사 24장과 경기복 24장은 제공된 jsDelivr 주소에 연결되어 있습니다. 이미지를 바꿔도 캐시 때문에 바로 반영되지 않을 경우 URL 끝에 ?v=2처럼 버전을 추가하세요.

## 구성

- index.html: 페이지 구조
- bright.css: PC·모바일 디자인
- main.js: 선수 선택, 의상 전환, 세계관 및 일정 화면
